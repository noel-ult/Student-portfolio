# Student portfolio HTML exercise

A static student portfolio with biography, technical skills, academic projects, contact form, and links. The sample identity is Johnny Black. The entire page is in `index.html`.

## Preview and customize

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Visit http://localhost:8000. Replace the sample identity, project details, and links in the HTML before publishing. No dependencies or build step are required.

The contact form uses `mailto:your_email@example.com`. Replace that placeholder with your intended address. Submission relies on the visitor's configured email client; there is no server-side mail delivery, account system, or database.

## Verification and hosting

Check navigation, contact links, keyboard access, and responsive layout manually. The page can be served by any static host. No automated test suite is included.
